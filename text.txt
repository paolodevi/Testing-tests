Yes. The symbol you're referring to is the standard center of gravity (CG) or center of mass marker used in engineering drawings and CAD software:

◴

Conceptually, it is:

a circle,

divided by a horizontal and a vertical line,

with alternating black and white quadrants.


Since MATLAB has no built-in marker for this, the easiest approach is to draw it as a set of patches in 3D. The nice thing is that you can orient it in any plane.

Here's a function that draws the symbol centered at any point P = [x y z]:

function drawCG(P,R,normal)

% P      = [x y z] center
% R      = radius
% normal = normal vector of the disk

normal = normal(:)/norm(normal);

% Build two orthogonal vectors spanning the disk
if abs(dot(normal,[0;0;1])) < 0.99
    u = cross(normal,[0;0;1]');
else
    u = cross(normal,[0;1;0]');
end
u = u/norm(u);
v = cross(normal,u);

theta = linspace(0,pi/2,40);

% Alternating colors
cols = {[0 0 0],[1 1 1],[0 0 0],[1 1 1]};

hold on

for k = 0:3

    t = theta + k*pi/2;

    pts = [zeros(1,length(t)+1);
           [0 cos(t)]*R;
           [0 sin(t)]*R];

    XYZ = P(:) + u*pts(2,:) + v*pts(3,:);

    patch(XYZ(1,:),XYZ(2,:),XYZ(3,:),cols{k+1},...
        'EdgeColor','none');
end

% Outer circle
tt = linspace(0,2*pi,200);
XYZ = P(:) + R*(u*cos(tt)+v*sin(tt));

plot3(XYZ(1,:),XYZ(2,:),XYZ(3,:),'k','LineWidth',1.5)

% Cross
for ang = [0 pi/2]
    p1 = P(:)-R*(u*cos(ang)+v*sin(ang));
    p2 = P(:)+R*(u*cos(ang)+v*sin(ang));

    plot3([p1(1) p2(1)],...
          [p1(2) p2(2)],...
          [p1(3) p2(3)],...
          'k','LineWidth',1.5)
end

axis equal
end

Example

figure
hold on
grid on
axis equal
view(3)

% Example point
P = [2 3 1];

drawCG(P,0.2,[0 0 1])

scatter3(P(1),P(2),P(3),50,'r','filled')

This produces a proper engineering-style CG symbol lying in the plane whose normal is normal. If your aircraft can rotate, you can simply pass the body's local z-axis (or whichever axis you want the symbol to face), and the CG marker will rotate with the aircraft.
